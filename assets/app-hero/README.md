## 跟现有资产的区别

| 类型 | 文件夹 | 风格 |
|------|--------|------|
| 标准 mascot 8 态 | `mascot/` | 扁平 spec sheet 同款 |
| 3D 旗舰形象 | `mascot-3d/` | 立体磨皮 3D |
| **App Hero**（本目录） | `app-hero/` | **高完成度营销级插画**（比 mascot 更细节） |

## 命名建议

- `01-` / `02-` / `03-` 前缀 = 风格优先级
- `flat-` / `3d-` = 风格类型
- 描述部分用小写连字符
